# Security Policy

## Reporting

Report vulnerabilities via GitHub Security Advisories or private email to the repo owner. Do not open public issues for secrets or exploits.

## Scope

This is a research-only paper trading information system. No live trading, no custody, no withdrawal paths. Security controls (redaction, lineage, gates) are research design, not a certified product.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.52.x  | Yes       |
| < 0.52  | No        |
